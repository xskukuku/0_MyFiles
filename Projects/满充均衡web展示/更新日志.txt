### 主要改进

**原始代码结构：**
```c
if (voltMax >= BALANCE_CHGVOLTLVL1) {
    // 分支3
} else {
    if (voltMax < BALANCE_CHGVOLTLVL0) {
        // 分支1
    } else {
        // 分支2
    }
}
```

**重构后的代码结构：**
```c
// 先统一计算uBalanceDeltVolt
if (uCellVoltMax < BALANCE_CHGVOLTLVL0) {
    // < 3450mv
} else if (uCellVoltMax >= PRO_CHG_CELL_VOLT_MAX) {
    // >= 3650mv
} else if (uCellVoltMax < BALANCE_CHGVOLTLVL1) {
    // 3450-3500mv
} else {
    // 3500-3650mv
}

// 检查是否需要清除均衡标志
if (uCellVoltDiff <= uBalanceDeltVolt) {
    return;
}

// 然后根据电压范围计算其他参数
if (uCellVoltMax >= BALANCE_CHGVOLTLVL1) {
    // 高压区域逻辑
} else {
    // 低压区域逻辑
}
```

### 优势

1. **更清晰** - 先计算压差阈值，再判断是否清除，最后计算其他参数
2. **更易读** - 电压区间判断更直观
3. **更易维护** - 逻辑分层更合理
4. **结果一致** - 计算结果与原版本完全相同
